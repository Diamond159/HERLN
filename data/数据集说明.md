# 数据集说明与可复现性声明

## 1. 使用的数据集

本文实验基于以下四个公开时序知识图谱数据集：

- ICEWS14
- ICEWS18
- WIKI
- YAGO

以上数据集在时序知识图谱推理与事件预测任务中被广泛采用。

---

## 2. 数据来源与获取方式

**ICEWS 系列（ICEWS14 / ICEWS18）**

- 来源：Integrated Crisis Early Warning System（ICEWS）
- 获取方式：通过官方发布渠道，或使用学界已整理的标准划分版本（http://www.icews.com/）

**WIKI**

- 来源：Wikidata 知识库
- 官网：https://www.wikidata.org/
- 提供结构化的百科全书式知识数据，可通过 Wikidata 数据转储或 SPARQL 端点访问

**YAGO**

- 来源：YAGO 知识库（由 Max Planck Institute 维护）
- 官网：https://yago-knowledge.org/
- 融合 Wikipedia、WordNet 与 GeoNames 等多源数据，提供带时间标注的知识图谱版本

---

## 3. 数据格式

所有数据统一整理为时序知识图谱四元组格式：
```
(s, r, o, t)
```

各字段含义如下：

| 字段 | 含义 |
|------|------|
| `s`  | 主语实体（subject） |
| `r`  | 关系（relation） |
| `o`  | 客体实体（object） |
| `t`  | 时间戳（timestamp） |

示例（文本形式）：
```
USA         make_statement    China      2018-05-01
BarackObama  wasBornIn        Hawaii     1961-08-04
```

示例（ID 形式）：
```
12  5  27  20180501
```

## 4. 数据预处理流程

为保证不同数据集间的处理一致性，本文执行以下标准化步骤：

**（1）时间离散化**

将原始时间戳映射为连续离散时间步（以年或天为单位划分，依数据集粒度而定）。

**（2）实体与关系编码**

分别构建 `entity2id` 与 `relation2id` 映射表，将文本形式统一转换为整数 ID。

**（3）数据集划分**

按时间顺序依次划分为训练集（Train）、验证集（Valid）与测试集（Test），确保时序上的严格不泄露。

**（4）历史子图构建**

对每个目标时间步 $t$，构建长度为 $L$ 的历史子图序列：

$$\{G_{t-L},\ \dots,\ G_{t-1}\}$$

作为模型的时序上下文输入。

## 5. 预处理脚本说明

附录提供以下脚本与接口：

- 数据清洗脚本
- `entity2id` / `relation2id` 映射生成脚本
- 历史子图序列构建代码

主要功能包括：原始事件记录到四元组的格式转换、按时间排序与切分、动态图序列的生成与存储。
