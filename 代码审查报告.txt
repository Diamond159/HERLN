====================================
A. 项目概览
====================================

项目名称：DRPM-NSCV / Baseline: HERLN
项目类型：时态知识图谱推理的硕士论文实验代码
主要数据集：ICEWS14, ICEWS18, WIKI, YAGO
核心模型：RecurrentRGCN（基于Hawkes过程的关系图卷积网络）
创新模块：
1. FFT频域分解与正则
2. 关系上下文先验（Logit偏置）
3. 全局关系动态建模（ERD-Net）
4. 复制-生成机制（Copy-Generation）
5. 周期趋势时序编码
6. Lie群正则化

执行链路：
1. 数据加载：src/knowledge_graph.py → load_from_local()
2. 时间切分：src/utils.py:639 split_by_time()
3. 历史窗口构建：src/main.py:84, src/utils.py:319 build_sub_graph()
4. 社区图构建：src/utils.py:852 new_class_graph()
5. 模型训练：src/main.py:365 epoch循环
6. 模型测试：src/main.py:54 test()函数
7. 结果输出：checkpoints/*/results.csv

代码规模：
- 主要模块：10+个Python文件
- 代码行数：约5000+行
- 实验脚本：experiments/目录（已被gitignore）

【中等】B2. 评测过滤逻辑不一致
位置：src/utils.py:488-506, src/utils.py:608-626
问题描述：
filter_score() 和 filter_score_r() 两个函数的过滤逻辑实现不同，
但都用于评测，可能导致实体预测和关系预测的评测标准不一致。

代码片段：
```python
# src/utils.py:488-506 - 实体预测过滤
def filter_score(test_triples, score, all_ans):
    test_triples = test_triples.cpu()
    for _, triple in enumerate(test_triples):
        h, r, t = triple
        ans = list(all_ans[h.item()][r.item()])
        ans.remove(t.item())  # 移除目标实体
        ans = torch.LongTensor(ans)
        score[_][ans] = -10000000  # 将其他候选设为极小值
    return score

# src/utils.py:608-626 - 关系预测过滤
def filter_score_r(test_triples, score, all_ans):
    test_triples = test_triples.cpu()
    for _, triple in enumerate(test_triples):
        h, r, t = triple
        ans = list(all_ans[h.item()][t.item()])  # 注意：这里是 (h, t) 键
        ans.remove(r.item())
        ans = torch.LongTensor(ans)
        score[_][ans] = -10000000
    return score
```

影响程度：中等
影响范围：评测结果的可比性
建议修复：统一过滤逻辑，或明确说明差异的合理性
